# Introduction to Web Infrastructure Design

This repository contains a set of web infrastructure design exercises showing how a web application can evolve from a simple single-server setup to more resilient, secure, monitored, and separated architectures.

The project focuses on understanding the role of each infrastructure component, how requests move through a web stack, and what limitations appear as traffic, availability, security, and operational requirements increase.

## Learning goals

This project covers:

- DNS and A records
- Web servers such as Nginx
- Application servers and application code
- Databases such as PostgreSQL/MySQL
- TCP/IP communication
- Load balancing and redundancy
- Single points of failure (SPOF)
- Active-active and active-passive concepts
- Database primary/replica concepts
- HTTPS, firewalls, and monitoring
- Separated infrastructure tiers
- Capacity and scaling considerations
